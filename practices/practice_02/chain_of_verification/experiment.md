## Исправленный результат

Исходная формулировка → Новая формулировка (дословно из ADR) → Основание исправления

- «OUT-1: … закреплён JSON-схемой…» (Решение, пункт 4) → «OUT-1: единый формат ответа и контракт на структуру — summary, risks (≤3), checks; планируется закрепить JSON-схемой (валидация — на уровнях unit/integration); детерминированный порядок risks по file asc, затем line asc.» → В рассмотренных материалах не представлена фактическая JSON‑схема и результаты её валидации; tests_unit.md содержит план.
- «Примечание: Возврат 200 и сохранение OUT-1 позволяют пайплайну CI продолжать автоматическую обработку, фиксируя факт деградации…» (Контролируемый ответ) → «Ожидаемый эффект: возврат 200 и сохранение OUT-1 должны позволять пайплайну CI продолжать автоматическую обработку, фиксируя факт деградации в checks и OBS-метриках; подтверждение требует интеграции с CI и проверки наличия OBS-метрик.» Дополнение в ADR: поведение клиента должно различать нормальный результат и деградацию по `checks`; HTTP 200 сам по себе не гарантирует продолжение обработки; дополнительные метрики — проектное решение вне OBS-1. → CASE.md/контекст не представляют evidence интеграции CI; указано требуемое поведение клиента для проверки.
- «Соответствие правилам SEC-1, API-1, REL-1, OUT-1.» (Положительные последствия) → «Ожидаемое соответствие правилам SEC-1, API-1, REL-1, OUT-1 после реализации по ADR и прохождения проверок.» → В рассмотренных материалах не представлены результаты выполнения тестов; TRAINING_PR.diff показывает текущее несоответствие учебного кода.
- «Увеличение латентности из-за редактирования и валидации.» (Ограничения) → «Ожидаемое увеличение латентности из-за редактирования и валидации; подтверждение — нагрузочные замеры по плану tests_load.md.» Дополнение: предложено сравнение до/после включения обработки секретов и валидации при одинаковых входах, нагрузке, окружении и заглушке LLM (tests_load.md задаёт общие условия; сравнение — дополнение к будущей проверке, не утверждается как выполненное). → В рассмотренных материалах не представлены результаты замеров; уточнён способ будущей проверки.

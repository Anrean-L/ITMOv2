# Контракт интерфейса UI

[Общий контракт UI и бэкенда](../../ui-backend-contract.md) — единственный согласованный источник для протокола и безопасности; этот документ фиксирует обязанности UI и не меняет его.

- Файл выбирается явно; UI показывает имя и отправляет один файл в `file` через `POST /api/analysis`, с `X-Csvpeek-Request: 1`, на текущий origin. Пользователь не должен запускать анализ повторно во время текущей попытки; выбор другого файла остаётся доступным.
- Успех отображается после проверки структуры и инвариантов модели. Строки и столбцы показываются с исходным порядком, дубликатами, нулями и доступными обозначениями пустого имени и BOM.
- Ошибки `empty_csv`, `invalid_encoding`, `invalid_structure` и `limit_exceeded` объясняют, что исправить; `invalid_request`, `unsupported_media_type`, `internal_error`, 403, неизвестный код, неверный ответ и сбой сети дают безопасное общее сообщение и возможность повтора. Известные безопасные детали показываются только по назначению. Данные и сообщения не интерпретируются как HTML.
- Статус и ошибки объявляются вспомогательным технологиям; все действия имеют подписи и доступны клавиатуре. Контраст, увеличение, размеры целей и ширины — как в FR-008–FR-010 спецификации. Переходы и поведение опоздавших ответов — в [модели](../data-model.md).
- Сервер отвечает за проверки `Host`, `Origin`, CORS, безопасность до разбора и кэша, лимиты и правила хранения; UI обеспечивает заголовок и обработку отказа. Сквозные проверки выполняются совместно при готовом сервере.

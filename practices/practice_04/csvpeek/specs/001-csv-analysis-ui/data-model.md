# Модель данных и состояний UI

Источник правил: [спецификация](spec.md), [принятый контракт](../ui-backend-contract.md). Данные живут в памяти страницы и не сохраняются персистентно.

## Сущности

- **Выбор**: один объект файла, исходное имя, размер; отсутствие выбора допустимо. Отмена диалога не изменяет выбор. Имя не приходит из результата.
- **Попытка**: уникальный для страницы идентификатор, связанный с конкретным выбором; только актуальная попытка может изменить отображение. Новый выбор или новый запрос делает старый ответ неактуальным.
- **Результат**: неотрицательные целые `row_count`, `column_count`; упорядоченный массив `columns` длиной `column_count`. Каждый элемент содержит строку `name` и неотрицательный целый `missing_count`, не больше `row_count`. Позиция — индекс массива плюс один; имена могут повторяться или быть пустыми. Недопустимый ответ не отображается как результат.
- **Ошибка**: локальная категория или стабильный код сервера, безопасный текст и действие; при наличии проверенных подробностей — номер логической записи и количество полей или вид и значение лимита. Серверное сообщение не исполняется как разметка.

## Переходы

| Состояние | Событие | Следующее состояние |
| --- | --- | --- |
| Начальное | Выбор файла | Выбран; видно имя и доступен анализ. |
| Выбран / успех / ошибка | Запуск текущего файла | Загрузка; виден статус, повторный запуск отключён. |
| Загрузка | Корректный ответ актуальной попытки | Успех; показываются все позиции по порядку. |
| Загрузка | Ошибка актуальной попытки | Ошибка; показываются причина и действие. |
| Любое | Выбор другого файла | Выбран; прежние ошибка и результат очищаются, старые ответы игнорируются. |
| Любое | Отмена выбора | Текущее состояние сохраняется. |
| Ошибка | Повтор | Новая попытка и загрузка. |

Одинаковое имя файла не идентифицирует попытку. Смена выбора при загрузке не гарантирует прекращения работы сервера. Пустое имя показывается с номером позиции как «Без имени»; BOM первого имени показывается отдельной текстовой пометкой и не удаляется. При нуле записей все значения пропусков равны 0; пометка «Все значения пусты» допустима лишь при ненулевом числе записей и равенстве пропусков числу записей.

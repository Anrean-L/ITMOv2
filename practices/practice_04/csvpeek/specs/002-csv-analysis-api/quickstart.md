# Проверка после реализации

Сервер запускается отдельно от CLI. Сценарии UI требуют ресурсов команды UI.

## Подготовка

- Python 3.12+, корень репозитория: `PYTHONPATH=src python -m csvpeek.server --port 8000`. UI и API должны быть на том же origin. Существующий CLI запускается без изменений.
- CSV ограничен 10 МиБ; всё тело multipart ограничено 16 МиБ. Превышение общего ограничения даёт `400 invalid_request`, превышение именно файла — `413 limit_exceeded` с `file_bytes`. Новое ограничение тела требует учёта в общей интеграции.
- Выполнить `./scripts/check.sh`; для CSV-изменений соблюдать `csv-feature-workflow`, инспекцию примера и результат автоматической проверки.

## Проверки HTTP

После запуска сервиса подставить фактический порт в `PORT` и выполнить из корня репозитория:

```bash
curl -sS -H 'X-Csvpeek-Request: 1' -F 'file=@examples/people.csv' "http://127.0.0.1:$PORT/api/analysis"
```

Ожидается 200, 4 записи, 3 колонки `name`, `age`, `score` и пропуски 0, 1, 0. Запрос без специального заголовка должен вернуть 403. Форматы — в [HTTP-контракте](contracts/http-api.md); обрыв может не дать ответа.

## Набор приёмки

1. Проверить заголовок без данных, дублирующиеся и пустые имена, BOM, кавычки и многострочные записи, неверную кодировку, пустой файл, структуру и каждую границу лимита с числом и на единицу больше.
2. Проверить матрицу `Host`, `Origin` и специального заголовка из FR-020; в браузере проверить same-origin успех, отказ чужой формы и отсутствие разрешения preflight. Убедиться, что отказ не запускает разбор и не меняет кэш.
3. Тестовыми средствами проверить попадания и промахи, LRU, оба ограничения размера, ошибки, перезапуск, один разбор на конкурентный ключ, независимость разных ключей и отмену ожидания. Сверить ответы на попадании и промахе.
4. Проверить отсутствие содержимого и результатов в персистентных временных буферах и журналах. Проверить прерванную загрузку, завершение после отмены, поздний ответ и повтор.
5. Отдельно выполнить `PYTHONPATH=src python tests/benchmark_cache.py`: пять пар прогонов по 20 запросов, окружение, медианы среднего времени и относительное изменение; порога ускорения нет. Завершить `./scripts/check.sh`.
